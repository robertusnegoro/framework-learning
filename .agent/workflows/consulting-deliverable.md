# Consulting Deliverable Workflow

Use this workflow when producing a professional deliverable for a consulting engagement, such as a gap analysis, maturity assessment, implementation roadmap, or framework recommendation report.

## Steps

1. **Understand the client context**
   - Clarify: industry, organization size, regulatory environment, current maturity level.
   - Identify the business problem or objective (e.g., "improve IT governance," "prepare for cloud migration").

// turbo
2. **Select the relevant framework(s)**
   - Review existing framework materials in the repo to match the client's needs.
   - Use the **Framework Comparison** skill if the client needs a multi-framework approach.

3. **Assess current state (if applicable)**
   - Define assessment criteria based on the chosen framework's maturity model.
   - Produce a current-state summary with identified gaps.

4. **Develop recommendations**
   - Map gaps to specific framework practices, processes, or capabilities.
   - Prioritize recommendations by impact and feasibility.
   - Include a phased roadmap (quick wins → medium-term → strategic).

5. **Draft the deliverable**
   - Follow the **Content Authoring** skill for formatting standards.
   - Structure:
     - Executive Summary
     - Current State Assessment
     - Gap Analysis
     - Recommendations (prioritized)
     - Implementation Roadmap
     - Appendices (framework references, terminology)

6. **Review and finalize**
   - Ensure all recommendations tie back to specific framework components.
   - Verify regulatory/compliance references are accurate for the client's jurisdiction.
   - Remove any internal-only language; ensure the document is client-presentable.
   - Ask the user to review before marking complete.
